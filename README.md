# Gbolahan Akinola | Personal Authority Website

A responsive static personal website focused on digital transformation, AI, automation, governance, adoption, training and community. Built with HTML, CSS and JavaScript. No build tools or paid hosting required.

## Publish on GitHub Pages

### Recommended: use your personal GitHub Pages address

1. Sign in to https://github.com/itsabefe
2. Click **+** in the top-right, then **New repository**.
3. Name it exactly `itsabefe.github.io`.
4. Choose **Public** and create the repository.
5. Unzip this website ZIP on your computer.
6. In the new GitHub repository, choose **Add file → Upload files**.
7. Upload the four files from the unzipped folder: `index.html`, `styles.css`, `script.js`, and `README.md`. Upload the files, not the ZIP itself.
8. Commit the files to the `main` branch.
9. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save if required.
10. After the deployment finishes, your site should be available at **https://itsabefe.github.io**. First publication may take a few minutes.

### Alternative: a project website

Create a repository called `personal-website` instead and follow the same upload and Pages steps. The address will usually be `https://itsabefe.github.io/personal-website/`.

## Updating the website

You can edit `index.html` or `styles.css` directly on GitHub, or upload changed files. Each commit triggers a new deployment. Give it a few minutes to update.
